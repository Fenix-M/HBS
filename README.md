# Human Body Simulator 0.1.0

Первый фундаментальный этап для Paper 1.21.11.

## Требования
- Paper 1.21.11
- Java 21 JDK
- Gradle 8.14+ или 9.x

## Сборка
В папке проекта выполни:
```bash
gradle build
```
Готовый файл:
`build/libs/HumanBodySimulator-0.1.0.jar`

Скопируй JAR в папку `plugins/` сервера Paper и перезапусти сервер.

## Команды
- `/hbs status` — своя медицинская карта
- `/hbs inspect <ник>` — осмотр игрока (право `hbs.medic`)
- `/hbs reload` — перезагрузка конфигурации (право `hbs.admin`)

## Реализовано
- регистрация Paper-плагина;
- SQLite-хранилище;
- создание базового профиля при первом входе;
- реестр анатомических структур;
- базовые показатели крови, кислорода и сознания;
- просмотр профиля.

## Пока не реализовано
Повреждения, физиологические расчёты, ампутации, кастомная модель, GUI, инструменты,
кальчуга и обязательная отправка Resource Pack. Это запланированные следующие этапы.
Пустой Resource Pack не отправляется: сначала необходимо подготовить реальные ресурсы,
разместить ZIP по HTTPS и указать URL и SHA-1 в конфигурации.
